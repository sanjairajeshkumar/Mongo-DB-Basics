# Mongo-DB-Basics

## Project Overview
This project covers basic MongoDB operations using MongoDB Shell (`mongosh`). It includes database setup, CRUD operations, query operators, and a Library System use case.

## Tasks Covered

### 1. Database & Collection Setup
- Create the `studentDB` database.
- Create the `students` collection.

### 2. Insert Operations
- Insert a single document.
- Insert multiple student documents.

### 3. Read Operations
- Retrieve all student documents.
- Filter and retrieve specific student records.

### 4. Update Operations
- Update a single document.
- Update multiple documents and verify the results.

### 5. Delete Operations
- Delete a single document.
- Verify the collection after deletion.

### 6. Query Operators
- `$gt` — Greater than
- `$lt` — Less than
- `$in` — Match values from a specified list
- `$exists` — Check whether a field exists
- Conditional and combined filters

### 7. Library System Use Case
- Set up the library database and collection.
- Insert book records.
- Update a book record.
- Search books by genre and price.
- Perform combined searches using `$and`.

## Technologies Used
- MongoDB
- MongoDB Shell (`mongosh`)

## Key Learnings
- Database and collection management
- CRUD operations: Create, Read, Update, and Delete
- Document filtering using query operators
- Applying MongoDB commands to a practical Library System scenario
